# YUPS Knowledge Base

Welcome to the **YUPS** (Your Universal Prompt Straw-Boss) project documentation. This directory acts as the central knowledge base for the project, containing architectural decisions, product roadmaps, research notes, and legacy information.

## 📂 Directory Structure

### 🏗️ [Architecture](./architecture/)
Technical documentation, system design, and component breakdown.
- **[System Overview](./architecture/overview.md)**: High-level view of the monorepo components (CLI, API, Web, etc.).
- **[Git Workflow](./architecture/git_workflow.md)**: Branching strategy and repository management.

### 🚀 [Product](./product/)
Product vision, roadmaps, and task tracking.
- **[Vision](./product/product_vision.md)**: What is YUPS, the "Straw-Boss" concept, and core values (Safety, Polyglot).
- **[TODO](./product/TODO.md)**: Current active tasks and roadmap.

### 🧠 [Knowledge Base](./knowledge_base/)
General technical knowledge relevant to the project, such as Linux internals, Bash tricks, and reference material.
- *Contains guides on Bash hooks, `trap DEBUG`, `command_not_found_handle`, etc.*

### 🔬 [Research](./research/)
Experiments and findings related to AI models, LLM training, and data analysis.
- *Contains notes on Gemma, Ollama, RAG, and fine-tuning strategies.*

### 💭 [Thoughts & Meetings](./thoughts/)
Brain dumps, stream-of-consciousness notes, and logs from development sessions.
- *Preserves the "Why" and "How" of past decisions.*

### 🧱 [Snippets](./snippets/)
Loose code fragments, config examples, and temporary prototypes found in the notes.

> **Note to Contributors (and AI Agents):**
